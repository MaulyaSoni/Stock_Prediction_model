📊 WHAT IT DOES:

1. FETCHES REAL-TIME DATA
   └─ Connects to Finnhub API
   └─ Gets current stock prices
   └─ Updates every 30 seconds

2. LOADS YOUR MODEL
   └─ Looks for models in models/ directory
   └─ Supports .pkl and .h5 formats
   └─ Falls back to trend analysis if not found

3. MAKES PREDICTIONS
   └─ Uses current + historical data
   └─ Predicts next price movement
   └─ Provides confidence score

4. CALCULATES INDICATORS
   └─ Simple Moving Average (SMA-5, SMA-20)
   └─ Price momentum
   └─ Volatility
   └─ Trend analysis

5. PROVIDES TRADING SIGNALS
   └─ BUY: Price expected to go up
   └─ SELL: Price expected to go down
   └─ HOLD: No clear signal
