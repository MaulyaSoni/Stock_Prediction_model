HOW TO USE:

STEP 1: Install Dependencies
  $ cd ai-copilot
  $ pip install -r requirements.txt

STEP 2: Start Real-time Prediction API
  $ cd realtime-agent
  $ python enhanced_app.py
  → API running on http://localhost:8005

STEP 3: Start Web Dashboard (New Terminal)
  $ cd ai-copilot
  $ python app_integrated.py
  → Dashboard running on http://localhost:5000

STEP 4: Open in Browser
  http://localhost:5000

STEP 5: Make Predictions
  • Use web interface for visual predictions
  • Or use API endpoints directly

═════════════════════════════════════════════════════════════════════════════

API EXAMPLES:

Single Prediction:
  curl http://localhost:8005/api/predict/AAPL

Batch Predictions:
  curl -X POST http://localhost:8005/api/predict/batch \
    -H "Content-Type: application/json" \
    -d '{"symbols": ["AAPL", "GOOGL", "MSFT"]}'

Technical Indicators:
  curl http://localhost:8005/api/technicals/AAPL

Top Predictions:
  curl http://localhost:8005/api/top-predictions
